# Cicarelli Advogados — Site Replicator

Este projeto é uma recriação pixel-perfect do site Cicarelli Advogados, especializado em Direito da Saúde em Curitiba.

## Stack Utilizada

- **React 18** (Vite + TypeScript)
- **Tailwind CSS v4** (com design tokens HSL)
- **Framer Motion** (Animações premium)
- **shadcn/ui** (Componentes de alta qualidade)
- **React Router DOM** (Gestão de rotas)
- **React Helmet Async** (SEO dinâmico)
- **TanStack Query** (Otimização de dados)
- **Remixicon** (Ícones institucionais)

## Estrutura

- `src/components`: Componentes reutilizáveis (Header, Footer, SEO, FloatingButtons).
- `src/pages`: Páginas da aplicação.
- `src/data`: Camada de dados mockados (artigos, FAQs, localizações).
- `src/hooks`: Hooks customizados (Typewriter).
- `src/lib`: Utilitários e validadores (OAB Compliance).

## SEO & Conversão

O site foi otimizado para SEO local em Curitiba, com páginas dinâmicas por bairro e cidade, além de um forte foco em conversão via WhatsApp e canais de contato direto, priorizando a usabilidade para pessoas de maior idade.
